Privacy

Clear by design.

Last updated July 14, 2026

Portfolio website

This website does not require an account and does not intentionally collect personal information through the portfolio pages. Standard infrastructure logs may temporarily contain technical information such as an IP address, browser type, requested URL, and timestamp for security and reliability.

Document to Deck

The original DOCX or PDF is read locally in your browser and is not uploaded to this website. Extracted text, the document name, and the presentation preferences you select are sent through a Cloudflare Pages Function to Anthropic so Claude can create the presentation structure.

Uploaded document text and generated decks are not intentionally stored by this website. Do not submit information that you are not permitted to share with Anthropic or Cloudflare.

Security and untrusted content

Document text is treated as untrusted source material, never as application instructions. The AI model has no shell, file, browser, or external tool access. Generated content must pass a restricted data schema before it can be displayed or exported.

Google Slides

If you choose “Open in Google Slides,” Google asks you to authorize limited access to files created or used by this application. A short-lived Google access token is kept in browser memory and is used to upload the generated PowerPoint directly to your Google Drive for conversion. This website does not store your Google access token or request access to unrelated Drive files.

Service providers

Cloudflare provides website hosting, serverless functions, abuse protection, and network security. Anthropic processes extracted text to generate the deck. Google is involved only when you explicitly choose Google Slides. Each provider processes information under its own terms and privacy policy.

Retention and control

Refreshing or closing the tool clears its in-browser working state. You control downloaded HTML and PowerPoint files and any presentation created in your Google Drive. Operational logs are designed to exclude document text, generated slide content, API credentials, and Google access tokens.
